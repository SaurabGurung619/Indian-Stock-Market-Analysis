# Indian-Stock-Market-Analysis
Analyzed real-time and historical stock-market data for 10 Indian companies using Python, yFinance, Pandas, and Jupyter Notebook. Built candlestick and stock-price charts using customized Python charting code and developed an interactive Power BI dashboard to visualize OHLC prices, trading volume, price trends, and company performance.

This project focuses on analyzing approximately **6 years of historical stock-market data up to the present** for 10 different Indian companies. I collected the data from **Yahoo Finance** using Python and yFinance and processed it in Jupyter Notebook using Pandas.

The analysis includes key stock-market metrics such as **Open, High, Low, Close (OHLC), Adjusted Close, trading volume, and price movements**. For advanced visualization, I **adapted and customized candlestick and stock-chart code from an external open-source GitHub source**, integrating it into the analysis to visualize historical price movements more effectively.

After processing the data, I used **Power BI** to build an interactive dashboard where users can select different companies and analyze their historical performance through price trends, KPIs, trading volume, and other visualizations.

Overall, the project demonstrates my ability to **collect real-world financial data, automate data extraction with Python, clean and analyze large historical datasets, implement external visualization code, and present analytical insights through Power BI**.
